# POLYBIUS

Check it out on [itch.io](https://abaddriver.itch.io/polybius)

## Installation & Requirements

1. Make sure you have Python installed along with the `pygame` library:

   ```bash
   pip install pygame
   ```


2. Run the game script:

   ```bash
   python polybius.py
   ```
